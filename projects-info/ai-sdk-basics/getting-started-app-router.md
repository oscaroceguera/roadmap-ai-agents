# ai-sdk-vercel/getting-started-app-router

**Purpose:** The official AI SDK "getting started" chat app for the Next.js App Router, kept as a reference baseline.

**What it does:** Minimal streaming chat UI + API route. README is the default `create-next-app` one.

**Stack:** Next.js, AI SDK, pnpm.

**Run:** `pnpm install && pnpm dev` → http://localhost:3000
